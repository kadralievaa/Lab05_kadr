1. В цикле while условие проверяется до выполнения тела цикла, а в do-while после. Это гарантирует выполнение кода минимум один раз.
2. Конструкция do-while обязательна для реализации меню в консольных приложениях, так как интерфейс должен отобразиться до первого ввода данных пользователем.
3. Если условие не изменяется внутри цикла, выполнение программы приведет к бесконечному циклу.
4. Конструкция цикла со счетчиком состоит из инициализации, условия продолжения и шага. Ее удобно использовать, когда заранее известно количество итераций.
5. Цикл foreach предназначен для последовательного перебора элементов коллекции, а for предоставляет доступ к элементам по их индексу.
6. Оператор break полностью прерывает выполнение текущего цикла, а continue пропускает оставшуюся часть текущей итерации и переходит к следующей.
7. Да, после выполнения оператора continue цикл продолжится со следующей итерации (с проверки условия или шага обновления). Иначе мог возникнуть бесконечный циклю
8. Оператор break завершает работу только того цикла, внутри которого он находится, не влияя на внешний цикл.
